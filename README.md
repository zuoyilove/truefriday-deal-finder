TrueFriday is a real Black Friday deal finder: 38 Black Friday and Cyber Monday deals, each checked on Nov 27, 2026 at its store, with the product, store, store link, sale price, usual price, discount and check time, searchable and filterable by category, store and discount, with an honest verdict on every deal that says whether it is really a deal. The site is plain static files under app/ with no build step and no network request; the program at main.ts hands it in with its screenshots and dossier.json.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
